# Patrones de Diseño

## Objetivo

Este proyecto presenta ejemplos prácticos de implementación de tres patrones de diseño en Java:

- Singleton
- Observer
- Strategy

El objetivo es mostrar su funcionamiento mediante ejemplos simples y ejecutables.

## Requisitos

Para ejecutar los ejemplos se necesita:

- Java JDK instalado.
- Visual Studio Code, IntelliJ IDEA, Eclipse u otro IDE compatible con Java.

Para verificar que Java está instalado, abrir una terminal y ejecutar:

bash
java -version


## Ejecutar desde Visual Studio Code
Abrir la carpeta patrones de diseño en Visual Studio Code.
Verificar que Java esté instalado y que la extensión de Java esté disponible.
Ingresar a la carpeta src.
Elegir el patrón que se desea ejecutar:

src/singleton/Main.java
src/observer/Main.java
src/strategy/Main.java

Abrir el archivo Main.java correspondiente.
Presionar Run o Ejecutar sobre el método main.
Los resultados del ejemplo se mostrarán en la consola.

Opción 2: Ejecutar desde la terminal

Primero, ubicarse en la carpeta src del proyecto:

cd "patrones de diseño/src"

Luego, compilar el ejemplo que se desea ejecutar.

Singleton
javac singleton/*.java
java singleton.Main
Observer
javac observer/*.java
java observer.Main
Strategy
javac strategy/*.java
java strategy.Main

Cada comando ejecutará únicamente el ejemplo correspondiente al patrón seleccionado.
